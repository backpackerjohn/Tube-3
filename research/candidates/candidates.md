## Lane: ai

### C01. The Local AI Lab (working title)
- **Niche:** Local / self-hosted AI: running open-weight LLMs on your own hardware — build guides, model-vs-hardware benchmarks, private AI stack tutorials (Ollama, Open WebUI, llama.cpp), 'can $X hardware run model Y?' tests
- **Format:** 8-15 min screen-capture + benchmark-chart explainers with AI/cloned narration; original benchmark runs and cost math as the visual spine; no face needed
- **Why now:** Open-weight models (DeepSeek, Qwen, Llama) got good enough for daily work in 2025-26 while API costs and privacy worries push users local; used RTX 3090s (~$700-900) made entry cheap. r/LocalLLaMA is ~686k-890k members and growing fast (sources differ on exact count). Fresh 2026 videos in the niche are pulling 50k-320k views from channels of every size.
- **Competitors scanned:** Technically Tim (16300 subs); Digital Spaceport (93800 subs); VirtualizationHowto (108000 subs)
- **Monetization:** High-intent hardware audience: GPU/mini-PC/NAS affiliate links, sponsors already active in the space (Tailscale runs its own 58k-view tutorial — vendors pay for this audience). Tech/dev CPM is upper-tier (inference — not independently verified). Later: paid build guides / consulting funnels.
- **Production:** Medium. Needs one credible test rig (~$1-2k, e.g., used RTX 3090) to generate original benchmarks; per-video work is running tests + screen capture + charts + scripted narration. Solo-feasible on a weekly cadence.
- **Originality defense:** Every video is built on benchmarks and cost calculations you run yourself — original primary data, not reused footage. Scripted analysis of tradeoffs (quantization, VRAM, $/token) is genuine research output; screen recordings are your own.
- **Risks:** Model/tooling churn makes some tutorials stale in months (counter: hardware-tier and cost-math videos age slowly). Benchmark credibility requires actually owning hardware. Homelab generalists (Techno Tim, Christian Lempa 273k) can flood the topic when it trends.
